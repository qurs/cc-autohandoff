Hooks `cc-autohandoff` готовят handoff отдельной **gpt-6-luna** в Codex или
**claude-haiku-5-5** в Claude Code. Не пиши резюме вместо writer, не заменяй его модель,
не вызывай compact или fork. После порога не продолжай исходную задачу.

## Общие команды

Уведомление hook содержит каталог handoff и точные команды. В готовом пакете Windows x64
используй PowerShell и встроенный исполняемый файл:
`& '<plugin-root>/bin/cc-autohandoff.exe' status --session-dir '<directory>'`.
Ручная генерация: `& '<plugin-root>/bin/cc-autohandoff.exe' --platform codex generate --transcript '<absolute-jsonl-path>' --workspace '<absolute-workspace>'`;
для Claude Code укажи `--platform claude`. Установка Python не нужна.
В исходной версии для разработчиков вместо исполняемого файла запускают
`python <plugin-root>/scripts/handoff.py`; исходные hooks требуют Python 3.11+.
Корень плагина расположен на два уровня выше каталога этого навыка. Пути с пробелами
заключай в кавычки. Status, retry и retry-continuation восстанавливают платформу
из метаданных сессии.

После готовности дай абсолютные кликабельные ссылки на `HANDOFF.md` и
`START-NEXT-SESSION.txt`. В режиме `manual`, а также в CLI и IDE пользователь сам
открывает новый чат и вставляет стартовый текст. Не создавай чат, если hook этого не просит.

## Сбой writer

Сообщи пользователю ошибку из уведомления и сохрани ссылки на диагностику. Не выдавай
исходную переписку за готовый handoff. Повтор после устранения причины:
пользователь отправляет в этот же чат сообщение `CC_AUTOHANDOFF_RETRY`, либо выполняется
команда `retry` из уведомления, один раз. Пока handoff не готов, инструменты и compact
заблокированы, поэтому в Claude Code сообщение-маркер обычно удобнее.

Плагин не сохраняет снимок переписки. Если retry сообщает о несохранённом последнем
сообщении, запроси у пользователя его точный текст и передай через stdin с флагом
`--last-message-stdin`; не создавай файл с перепиской и не подменяй текст догадкой.

## Claude Code

Writer — отдельный процесс `claude --print`; вход, выполненный в приложении Claude,
он не наследует. Если уведомление или предупреждение `SessionStart` говорит, что writer
не авторизован (`authentication`, 401, «Not logged in»), попроси пользователя самого
выполнить в терминале `claude auth login` (или задать в `CC_AUTOHANDOFF_CLAUDE` путь
к авторизованному CLI). Не вводи учётные данные за пользователя. Затем — повтор
маркером `CC_AUTOHANDOFF_RETRY`.

В Claude desktop при `continuation.claude = claude-desktop` hook разрешает только:
1. `ToolSearch` с `{"query": "select:mcp__ccd_session__start_session", "max_results": 1}`,
   если инструмент сессий ещё не загружен;
2. один вызов `mcp__ccd_session__start_session` ровно с аргументами из уведомления hook.

Не меняй и не добавляй поля, не используй `fork`, worktree или shell вместо инструмента.
После подтверждения дай ссылку `[Новая сессия](#local_…)` с идентификатором из уведомления
и заверши старый чат. Если инструмент недоступен или отклонён, сообщи об этом и
остановись: пользователь откроет новый чат вручную по ссылке на стартовый текст.

## Codex

В Codex desktop при `continuation.codex = codex-desktop` разрешены только запрошенные
hook операции доставки через `list_projects`, `create_thread`, `navigate_to_codex_page`,
с точными аргументами hook. Не используй shell, App Server, fork или отдельную рабочую
CLI-сессию вместо инструментов приложения. После подтверждения создания выведи карточку
`::created-thread{threadId="..."}`; для очереди используй `clientThreadId`, не передавая
его инструменту открытия.

После `retry-continuation` пользователь отправляет в старый чат
`CODEX_HANDOFF_DELIVER:<имя каталога handoff>`. Команда сама не создаёт чат.

## Сбой доставки (обе платформы)

Сообщи ошибку и сохрани ссылки. Явный повтор:
`& '<plugin-root>/bin/cc-autohandoff.exe' retry-continuation --session-dir '<directory>'`.
Если создание могло выполниться (`uncertain`), сначала проверь список чатов или сессий;
только после проверки отсутствия продолжения допустим `--confirm-no-chat`. Не повторяй
создание, если уже известен `threadId`, `clientThreadId` или `local_…` новой сессии.
После доставки остановись.

## Новый рабочий чат

Единственный источник прежнего контекста — `HANDOFF.md`. Не читай, не ищи и не извлекай
старый чат, transcript, снимки переписки и логи writer через файлы или инструменты чатов.
Если сводке недостаёт сведений, спроси пользователя. Файлы проекта разрешено читать
для самой задачи. Стартовый текст нового чата — на английском.
