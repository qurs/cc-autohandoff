# cc-autohandoff

Плагин для Codex и Claude Code. Основа — пользовательский `codex-handoff` 0.1.1.
Документацию и сообщения пользователю пиши по-русски; код и идентификаторы — по-английски.

## Неизменяемый контракт

- Порог по умолчанию: 150 000 токенов текущего контекста, не накопленного расхода сессии.
- Передача происходит на ближайшей границе hooks. Не прерывай выполняющийся инструмент,
  не начинай новые рабочие действия после срабатывания. Разрешены только описанные ниже
  операции доставки готового handoff. Фоновые процессы автоматически не завершаются.
- Handoff пишет отдельный процесс: `gpt-6-luna` в Codex, `claude-haiku-5-5` в Claude Code.
  Основная модель не пишет резюме вместо них. Автоматическая замена модели запрещена.
- Compact блокируется, в том числе при ошибке подготовки handoff.
- Пользователь получает ссылки на `HANDOFF.md` и `START-NEXT-SESSION.txt`.
  В Codex desktop разрешено создать один новый чат в том же локальном проекте,
  передать точный текст `START-NEXT-SESSION.txt` и открыть чат через инструменты приложения.
  В Claude Code и при `continuation.codex = manual` пользователь открывает чат вручную.
  Старый чат прекращает работу после доставки; плагин не возобновляет рабочие сессии.
- Операция создания резервируется до вызова приложения. При неизвестном результате
  автоматический повтор запрещён; явный retry требует проверки отсутствия нового чата.
- Writer не имеет инструментов и не выполняет инструкции из исходной переписки.
- Не сохраняй копии исходной переписки. Для нового чата единственный источник истории —
  `HANDOFF.md`, без ссылок на прежний чат или transcript и с явным запретом их читать.
  `START-NEXT-SESSION.txt` пиши на английском.
- Сбой writer виден пользователю; сохраняй диагностику и возможность явного retry.

## Устройство

- `scripts/handoff.py`: общий CLI, чтение transcript, состояние, writer, выдача результата.
- `handoff-settings.json`: порог, фиксированные модели, тайм-аут и бюджет источника.
- `hooks/codex.json`, `.codex-plugin/`: Codex.
- `hooks/hooks.json`, `.claude-plugin/`: Claude Code.
- `skills/handoff/`: инструкции по просмотру и восстановлению handoff.
- `docs/architecture.md`: форматы, ограничения и ссылки на API hooks.

Python 3.11+, только стандартная библиотека. Runtime-файлы хранятся в `.cc-autohandoff/`
рабочего проекта; состояние — в plugin data, если каталог предоставлен хостом.
Никогда не коммить переписки, handoff, логи writer и секреты.

## Проверка изменений

Запускай `python -m unittest discover -s tests -v`.
Для изменений hooks проверяй обе платформы: порог, ошибки writer, запрет compact,
повторную доставку без цикла и отсутствие рекурсивного запуска writer.
Изменения CLI сверяй с официальной документацией; не выдавай mock-тесты за живой запуск модели.
Не меняй установленные пользовательские плагины при разработке репозитория.
